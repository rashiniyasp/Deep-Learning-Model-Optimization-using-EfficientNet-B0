Step-by-Step Methodology

The Optimization & Deployment Engineering Pipeline

From clinical dataset curation and compound-scaled convolutional representation learning to edge quantization, reliability calibration, and visual explainability.

01

Clinical Dataset & Problem Formulation

Utilizes 12,400 clinical ultrasound scans from Zenodo 3904280 across 6 anatomical classes: Fetal Brain (3,092), Fetal Abdomen (711), Fetal Thorax (386), Fetal Femur (1,047), Maternal Cervix (1,626), and Other (5,538). Evaluated on an isolated test split of 5,271 held-out scans.

Zenodo 3904280 Stratified Split Class Imbalance
02

EfficientNet-B0 Compound Scaling

Employs compound scaling balancing network depth, width, and resolution ($d=1.2, w=1.1, r=1.15$). Total footprint of 4.02M parameters and 0.39 GFLOPs, utilizing Mobile Inverted Bottleneck Convolutions (MBConv) with Squeeze-and-Excitation (SE) channel attention.

Compound Scaling MBConv Blocks Squeeze-and-Excitation
03

Optimization Dynamics & Convergence

Fine-tuned from ImageNet-21k pre-trained weights using AdamW optimizer (weight decay $1\times 10^{-2}$), Cosine Annealing learning rate schedule ($1\times 10^{-4} \to 1\times 10^{-6}$), and Label Smoothing (0.1) to prevent clinical overconfidence. Early stopping halted training at Epoch 24.

AdamW Optimizer Cosine Annealing Label Smoothing 0.1
04

Edge CPU Quantization & ONNX Export

Benchmarked across 4 runtime configurations on an AMD Ryzen 7 7730U laptop CPU. Compared PyTorch Dynamic INT8 quantization against ONNX Runtime graph optimizations (constant folding, node fusing). ONNX FP32 achieved 21.22 ms latency (47.1 FPS) with 3.0× model size compression.

ONNX Runtime Dynamic INT8 Graph Optimization
05

Post-Hoc Uncertainty Calibration

Implemented Temperature Scaling (Guo et al., ICML 2017) using L-BFGS optimization with positive reparameterization $T = \exp(s) > 0$. Optimal temperature $T^* = 0.8765$ reduced Expected Calibration Error (ECE) from 13.27% to 9.46% (28.8% relative reduction), preserving top-1 predictions.

Temperature Scaling ECE Reduction L-BFGS Optimization
06

Interpretability & Manifold Projections

Extracted penultimate 1,280-dimensional feature representations for all 5,271 test images and mapped them via t-SNE and UMAP to verify anatomical plane separability. Generated native Grad-CAM saliency heatmaps targeting the final MBConv block to confirm focus on acoustic landmarks.

💡 Medical Edge Deployment Insight: ONNX FP32 provides the premier Pareto-optimal operating point on modern laptop CPUs, achieving 21.22 ms latency (47.13 FPS) and 15.30 MB disk footprint (3.0× compression) with zero accuracy degradation. PyTorch Dynamic INT8 delivers identical 3.0× compression and 100% accuracy retention, providing a pure PyTorch deployment path without ONNX dependency.
